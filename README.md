# Task Management Application

## Overview
A Full Stack Task Management Application developed using React, Flask, SQLite and Bootstrap.

## Features

- User Registration
- User Login
- Dashboard
- Add Task
- Delete Task
- Search Tasks
- Responsive Design
- REST API
- SQLite Database

## Technologies Used

### Frontend
- React
- Vite
- Bootstrap 5
- Axios

### Backend
- Flask
- Flask SQLAlchemy
- Flask CORS

### Database
- SQLite

## Installation

### Frontend

cd frontend

npm install

npm run dev

### Backend

cd backend

pip install -r requirements.txt

python app.py
